INICIO
Extrae todo el ZIP en una carpeta y ejecuta OPC Connector.exe.
Conserva las carpetas que lo acompañan: no muevas solo el ejecutable.
Crea una conexión, configura sus parámetros y pulsa Guardar conexión.
En Tags importa o crea variables según el driver; revisa tipo, dirección y permisos.
Configura OPC DA/UA y la API REST opcional; inicia la adquisición y publicación.
La aplicación debe permanecer abierta. No incluye servicio de Windows.
OPC DA requiere .NET Framework 4.8 y OPC Core Components por separado.
